ตั้งค่า · Settings

ค่าที่ตั้งครั้งเดียวแล้วทุกโมดูลใช้ร่วมกัน — เก็บไว้ในเครื่องนี้เท่านั้น

🔗 การเชื่อมต่อข้อมูล ใช้โดย เทียบ Order · ค้นหาออเดอร์

แท็บเทียบ Order และหน้าค้นหาออเดอร์ดึงออเดอร์ของวันนี้จาก URL นี้
ใส่ URL เดียวกับออเดอร์ได้ ถ้า Apps Script ตัวนั้นรับ ?api=stock — แต่ถ้าตอนนี้ deploy แยกกันอยู่ ให้ใส่คนละอันตามเดิม ระบบเติม ?api= ให้เอง
ทำให้ไฟล์รถบริษัทที่ทีมขนส่งอัป ข้ามไปเครื่องอื่นได้ — ไม่ใส่ก็ยังใช้โมดูลได้ตามปกติ แต่ไฟล์จะอยู่แค่ในเครื่องที่อัป เป็นคนละ URL กับสองช่องบน — transport-api.gs ต้องอยู่ในชีตของตัวเอง เพราะสคริปต์ออเดอร์และสต๊อก ใช้ doGet ของตัวเองไปแล้ว และหนึ่งโปรเจกต์มีได้ตัวเดียว
ช่องขวาไม่ใช่การล็อกอิน แค่ให้คนที่มาเลือกไฟล์รู้ว่าใครอัปมา เวลามีไฟล์สองไฟล์ของวันเดียวกันจะได้ไม่ต้องเดา

🖼️ โลโก้บริษัท ใช้บน ใบนำส่งสินค้า

ยังไม่มีโลโก้
PNG หรือ JPG · เก็บเป็นรูปในเครื่องนี้ ไม่ได้อัปขึ้นที่ไหน

👥 ผู้ใช้และรหัสเข้าระบบ

รหัสถูกเก็บเป็นค่า hash พร้อม salt ต่อคน ไม่ได้เก็บตัวรหัสเอง — แต่ด่านนี้เป็น ป้ายหน้าประตู ไม่ใช่กุญแจ มันกันคนเดินผ่านหยิบเครื่องไปกด ไม่ได้กันคนที่ตั้งใจ และข้อมูลทั้งหมดอยู่ในเบราว์เซอร์เครื่องนี้เท่านั้น

💾 สำรอง / กู้คืนการตั้งค่า

ทุกอย่างในหน้านี้เก็บอยู่ในเบราว์เซอร์เครื่องนี้เท่านั้น ไม่มีเซิร์ฟเวอร์เก็บให้ — ล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่องแล้วกู้เองไม่ได้ เก็บไฟล์นี้ไว้ที่ปลอดภัย ไม่ควรส่งในแชทกลุ่ม เพราะข้างในมีรายชื่อผู้ใช้และรายชื่อสินค้าทั้งหมด
ไม่รวมข้อมูลของวัน (ออเดอร์ / สต๊อก / ไฟล์รถบริษัท) และไม่รวมการล็อกอินของคุณ
